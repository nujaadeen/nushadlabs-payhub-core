PayHub Demo

Manual testing tool for the payhub-core API - plain HTML + fetch(), no framework, no build step. This page is served completely separately from Django (see demo/README.md); it talks to the real API purely over HTTP from the browser. Every response is shown as raw JSON in the box under each step.
